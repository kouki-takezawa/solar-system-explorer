# Solar Explorer — 太陽系タイムトラベル・ビジュアライザー（デモ）

🔗 **本番URL**: [https://solar-system-explorer-inky.vercel.app](https://solar-system-explorer-inky.vercel.app)

## これは何のリポジトリか

**Solar Explorer** は、太陽系から恒星近傍・銀河系・観測可能な宇宙まで、シームレスなズームで行き来しながら、時間軸を自由に操作して探索できる**3D宇宙ビジュアライザー**です。ブラウザ上で動作し、Three.js（react-three-fiber）でリアルタイムに描画しています。

太陽・惑星・月はケプラー軌道要素から毎フレーム位置を計算しているため、タイムコントローラーで日時を進めたり戻したりすると、実際の公転・自転に基づいて天体が動きます。「1970年の地球はどこにあったか」「2050年の火星は？」といった“時間旅行”をしながら宇宙のスケール感を体感できることがこのアプリの一番の狙いです。ISSやボイジャーなどの実在する探査機も、実際の打ち上げ・到達日と連動して登場します。

肩の力を抜いて眺めても楽しめるビジュアル重視のデモ実装であり、教育・鑑賞・技術デモを目的としています（探査機ナビゲーション級の精度を持つシミュレーターではありません）。

## 主な機能

**太陽系（Phase 1–2）**
- 太陽＋8惑星＋月をケプラー軌道要素から毎フレーム計算し、実際の公転・自転に基づいて配置
- 太陽・惑星・月には実写ベースのテクスチャを使用（Wikimedia Commonsでホストされる Solar System Scope の CC BY 4.0 素材／地球のみ NASA 由来の three.js 公式サンプル素材）。土星の環は放射状UVマッピングによるテクスチャリング
- タイムコントローラー：再生/停止、±30日ステップ、速度プリセット（0.5×〜1年/秒）、日時直接入力、1970–2050年の広域タイムライン
- 天体クリックでの選択、GSAPによるカメラのスムーズなフライトゥ演出
- カメラモード：フリーカメラ / 天体追従 / 探査機視点（近接フレーミング＋追従）
- 左サイドバー：検索、Overview / Telemetry / Missions タブ（Telemetryは選択中天体のリアルタイム太陽・地球距離、通信遅延、公転速度を表示）
- 距離スケール切り替え（ログスケール / 実寸スケール）

**探査機（Phase 3）**
- ISS・ハッブル宇宙望遠鏡（地球周回）、ジュノー（木星の極軌道）、パーサヴィアランス・キュリオシティ（火星表面の固定地点）、ボイジャー1号・2号（太陽圏を離脱した恒星間軌道）を実装
- 実際の打ち上げ／着陸日以前は太陽系ビューに登場しない（タイムトラベルと連動）
- 探査機はglTFではなく手続き生成の低ポリモデル（外部アセットホストへの依存を避けるための設計判断）

**宇宙スケール**
- 太陽系 → 恒星近傍（実在する16の近傍恒星）→ 銀河系（手続き生成した渦状腕モデル）→ 観測可能な宇宙（対数スケールの模式図）を、スクロールでのシームレスなズームまたは上部タブで行き来可能
- 地球を選択してさらにズームインすると、実際にカメラが見ていた方角から衛星画像の2Dマップ（Leaflet + Esri World Imagery、無料タイル）へフェード遷移。「現在地へ」ボタンでブラウザの位置情報を使用可能
- サイバネティクス系ダークテーマ、Bloomポストプロセッシングによるネオングロー
- モバイル幅ではサイドバーがドロワー化するレスポンシブ対応

## 技術スタック

React 19 + TypeScript + Vite（提案書ではNext.jsでしたが、SSRが不要なクライアント3Dアプリのためデモでは軽量なViteを採用）/ three.js + @react-three/fiber + @react-three/drei + @react-three/postprocessing / zustand / gsap / Leaflet / Tailwind CSS v4

Earth の2Dマップ（Leaflet）は初回アクセス時にはダウンロードされず、実際に地球へダイブした時点で遅延読み込みされます（`React.lazy` によるコード分割）。

## ディレクトリ構成

```
src/
├─ App.tsx           # アプリのルートコンポーネント
├─ main.tsx          # エントリーポイント
├─ components/
│  ├─ scene/         # 3Dシーンを構成するコンポーネント（惑星・探査機・ラベル・選択リングなど）
│  └─ ui/            # サイドバーやタイムコントローラーなどの2D UI
├─ hooks/            # 選択状態管理など横断的なロジックを担うカスタムフック
├─ lib/              # 軌道計算・座標変換・位置レジストリなどのドメインロジック
├─ data/             # 惑星・恒星・探査機などの静的データ定義
├─ store/            # zustandによるグローバル状態管理
└─ types.ts          # 共有の型定義
```

## 起動方法

```bash
npm install
npm run dev
```

`http://localhost:5173/` を開いてください。

## アーキテクチャメモ

- `src/hooks/useSelectableBody.ts` … クリック/ホバー/選択状態/カメラ用半径登録を一元化する共有フック。惑星・月・探査機・恒星マーカーすべてがこれを使用
- `src/components/scene/BodyLabel.tsx` / `SelectionRing.tsx` … 3D空間上のラベルと選択リングの共通コンポーネント
- `src/lib/positionsRegistry.ts` / `radiusRegistry.ts` … 天体IDから現在位置・カメラ用半径を引けるモジュールレベルのレジストリ（Reactの再レンダーを介さずにフレームごとに更新するためのもの）
- `src/lib/planetGeo.ts` … 惑星表面の緯度経度とワールド座標系の相互変換（地球ダイブインの遷移先計算、火星表面探査機の配置の両方で使用）

## 既知の制約（デモ用途）

- 軌道計算はJ2000元期の平均軌道要素による簡易ケプラー計算です（摂動なし）。可視化用途としては十分な精度ですが、探査機ナビゲーション級の精度ではありません。ボイジャーの恒星間軌道は直近の実測距離からの線形外挿による近似です。
- 恒星近傍ビューの恒星は距離は実測値ですが、天球上の方向は模式的な配置です。
- 惑星ラベルの自動クラスタリング（ズームアウト時のグループ化表示）は未実装です。
- 地球の2Dマップは無料タイル（Esri World Imagery）のため、地域によって解像度・網羅性に差があります。
