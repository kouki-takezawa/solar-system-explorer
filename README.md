# Solar Explorer — 太陽系タイムトラベル・ビジュアライザー（デモ）

Three.js（react-three-fiber）による太陽系3D可視化アプリのデモ実装。ケプラー軌道要素から太陽＋8惑星の位置をリアルタイム計算し、時間軸を自由に操作しながら太陽系を探索できます。

## 起動方法

```bash
npm install
npm run dev
```

`http://localhost:5173/` を開いてください。

## 実装済み機能（Phase 1–2 相当）

- 太陽＋8惑星をケプラー軌道要素から毎フレーム計算し、実際の公転・自転に基づいて配置
- タイムコントローラー：再生/停止、±30日ステップ、速度プリセット（0.5×〜1年/秒）、日時直接入力、1970–2050年の広域タイムライン
- 天体クリックでの選択、GSAPによるカメラのスムーズなフライトゥ演出
- カメラモード：フリーカメラ / 天体追従（探査機視点はPhase 3で実装予定のプレースホルダー）
- 左サイドバー：検索、Overview / Telemetry / Missions タブ（Telemetryは選択中天体のリアルタイム太陽・地球距離、通信遅延、公転速度を表示）
- 距離スケール切り替え（ログスケール / 実寸スケール）
- サイバネティクス系ダークテーマ、Bloomポストプロセッシングによるネオングロー
- モバイル幅ではサイドバーがドロワー化するレスポンシブ対応

## 技術スタック

React 19 + TypeScript + Vite（提案書ではNext.jsでしたが、SSRが不要なクライアント3Dアプリのためデモでは軽量なViteを採用）/ three.js + @react-three/fiber + @react-three/drei + @react-three/postprocessing / zustand / gsap / Tailwind CSS v4

## 既知の制約（デモ用途）

- 軌道計算はJ2000元期の平均軌道要素による簡易ケプラー計算です（摂動なし）。可視化用途としては十分な精度ですが、探査機ナビゲーション級の精度ではありません。
- 探査機（ボイジャー、ハッブル等）の3Dモデル・軌道表示は未実装（Phase 3のロードマップ通り、ミッションタブにはテキスト情報のみ収録）。
- 惑星ラベルの自動クラスタリング（ズームアウト時のグループ化表示）は未実装です。
